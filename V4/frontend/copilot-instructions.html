🎯 What Are Copilot Instructions?

A copilot-instructions.md file tells AI assistants how to help you code better. It's like a cheat sheet for your project's rules and preferences.

🚀 Quick Start (3 Steps)

Step 1: Create the File

# In your project root
touch copilot-instructions.md

Step 2: Use This Simple Template

# [Your Project Name] Instructions

## Project Context
- Tech stack: [e.g., React, TypeScript, Node.js]
- Architecture: [e.g., Microservices, MVC, Component-based]

## Coding Standards
- Use strict mode for your language
- Follow established style guides
- Use consistent naming conventions
- Write clear, descriptive comments

## Testing
- Write unit tests for all functions
- Aim for 80%+ code coverage
- Test edge cases and error scenarios
- Use mocking for external dependencies

## Security
- Sanitize all user inputs
- Use HTTPS for all communications
- Validate data on both client and server
- Handle errors gracefully

Step 3: Customize for Your Project

Copy templates from this Copilot Prompter app and adapt them!

💡 Writing Tips

✅ Do This:

  • Be specific: "Use camelCase for variables" ✓
  • Show examples: Include code snippets
  • Keep it current: Update regularly
  • Prioritize: Important rules first

❌ Avoid This:

  • Being vague: "Use good naming" ✗
  • Too much text: Keep it scannable
  • Contradictions: Check for conflicts
  • Outdated info: Remove old patterns
